# @platen-reports/designer

React report designer for [Platen Reports](https://github.com/erikhuis/platen-reports).

> **This is a `0.0.0` placeholder.** It reserves the package name and the
> `@platen-reports` scope. There is no implementation in this release — do not
> install it expecting one.

The designer edits the JSON report definitions consumed by the
`PlatenReports.*` NuGet packages. All packages in the repository share one
version and are released in lockstep: **equal versions are conformant**.

See the [repository README](https://github.com/erikhuis/platen-reports#readme)
for scope, non-goals, and the versioning policy.
